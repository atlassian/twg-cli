# Changelog

The [Teamwork Graph CLI changelog](https://developer.atlassian.com/cloud/twg-cli/changelog/)
contains the full public release history, including stable and public beta notes.

## 1.4.8 (public beta and stable)

This release adds artifact file uploads, diffs between Bitbucket refs, and
file-based inputs for several Jira, Bitbucket, and JSM commands. The
[full 1.4.8 entry](https://developer.atlassian.com/cloud/twg-cli/changelog/#1-4-8---2026-11-25)
includes fixes and migration details for Bitbucket commit creation.
