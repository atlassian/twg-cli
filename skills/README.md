# TWG Agent Skills

These fully materialized public skills come from the TWG CLI 1.4.7 release
profile. Each package includes its license and supporting files.

## Offline essentials

| Skill | Purpose |
| --- | --- |
| [`twg`](twg/SKILL.md) | Core CLI guidance, command discovery, and output handling |
| [`twg-confluence`](twg-confluence/SKILL.md) | Confluence reads, authoring, and write safety |
| [`twg-jira`](twg-jira/SKILL.md) | Jira work items, queries, fields, and transitions |
| [`twg-setup`](twg-setup/SKILL.md) | Install, upgrade, authenticate, and repair TWG CLI |

## Workflow skills

| Skill | Purpose |
| --- | --- |
| [`twg-agentic-search`](twg-agentic-search/SKILL.md) | Search Atlassian and connected work sources |
| [`twg-artifacts`](twg-artifacts/SKILL.md) | Find, publish, update, and share Atlassian Artifacts |
| [`twg-code-review`](twg-code-review/SKILL.md) | Review pull requests and prepare findings |
| [`twg-context-discovery`](twg-context-discovery/SKILL.md) | Gather project context and map dependencies |
| [`twg-engineering-work`](twg-engineering-work/SKILL.md) | Explore pull requests, repositories, pipelines, and code |
| [`twg-jira-resolve-merged-work`](twg-jira-resolve-merged-work/SKILL.md) | Match Jira work items to merged pull requests |
| [`twg-operational-health`](twg-operational-health/SKILL.md) | Investigate incidents and review operational health |
| [`twg-responsibility-routing`](twg-responsibility-routing/SKILL.md) | Find owners, experts, and approvers |
| [`twg-space-creation`](twg-space-creation/SKILL.md) | Plan and build Confluence spaces |
| [`twg-status-rollups`](twg-status-rollups/SKILL.md) | Summarize work and assess decision readiness |

The [agent skills guide](https://developer.atlassian.com/cloud/twg-cli/agents/skills/)
covers CLI-managed updates and installation for supported agents. See the
[release integration guide](../docs/release-integration.md) for how to refresh
this snapshot.
