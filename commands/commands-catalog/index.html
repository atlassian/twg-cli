Teamwork Graph CLI Command Catalog

This catalog identifies which Teamwork Graph CLI commands require Rovo Credits and which are free to use without them. Commands that require Rovo Credits are classified as Enriched because they use advanced Teamwork Graph, GraphStore, Rovo Search, Collaboration Graph, or code intelligence capabilities. All other commands use direct product APIs or local CLI utilities and do not require Rovo Credits.
